## 1. 决定设计的数据事实（206 clip，3166 s 被描述，`runs/_scratch/l2_stats.py`）

1. **绝对档位 ≠ 动作。** 各 clip 静息值（中位数）p10/p50/p90：eyeSquintLeft 0.18/0.33/0.55，
   eyeBlinkLeft 0.06/0.14/0.29，browInnerUp 0.00/0.10/0.67。eyeSquintLeft 99% 的帧、eyeBlinkLeft 86%
   的帧不是 `none`。所以动作必须按"相对静息值的偏离"检测；按档位算的通道共现被常亮通道支配，没有意义。
2. **动作跨窗口。** 非 none 连续段（整段拼接后）的中位时长 / 超过 1 s 的比例：jawOpen 0.27 s / 13%，
   mouthSmileLeft 0.30 s / 12%，browInnerUp 0.65 s / 40%。头部旋转相对每个窗口的参考记录，跨窗口的
   点头会被拆开。
3. **左右关系各异。** 每帧档位左右一致率：嘴部约 0.90，眨眼 0.69，外眉 0.61，眯眼 0.62 → 短语带对称性参数。
4. **两眼同向。** eyeLookInRight 与 eyeLookOutLeft 的 Jaccard 0.92 → `gaze_shift` 是天然短语。
5. 6 个通道从未亮过（cheekPuff、cheekSquintL/R、jawForward、noseSneerL/R）。
6. 头部平移 91% 的帧不是 none：平移分档阈值按单 clip 定，需另行修正（L1 问题，不在本文范围）。

## 2. 格式

### 2.1 L1 与 L2 的区别

| | L1 | L2 |
|---|---|---|
| 单位 | 1 s 窗口，重叠 50% | 轨道（clip 的连续 segment），一条时间线 |
| 组织 | 按通道：`channels[通道] = [分段]`，稠密 | 按事件：`phrases = [动作]`，稀疏 + `rest` + `residual` |
| 词汇 | 57 通道 × 4 档 | 短语类型词表，每类有参数 |
| 数值 | 绝对值 | 相对 `rest` 的偏离 |
| 编辑 | 改某通道某段的档位 | 改一个动作的参数，模板展开到多通道 |

### 2.2 L2 文档

```json
{
  "format": "l2_text", "vocabulary_version": "0.1.0", "l1_rules_version": "1.0.0",
  "schema_version": "2.0.0", "gaze_unit": "...", "blendshape_names": [...], "target_hz": 30.0,
  "tracks": [{
    "track_id": "<clip_id>#<segment_id>", "clip_id": "...", "segment_id": 0,
    "track_start": 0, "time_sec": 229.30, "hz": 30.0, "n_frames": 596,
    "reference": {"head_rotation": {"x": -3.1, "y": 5.2, "z": 0.8}},
    "masks": {"is_padding": [], "is_gap_filled": [], "unobserved": [[12.4, 12.5333]]},
    "rest": {"eyeBlinkLeft": 0.1261, ..., "head_rotation": {"x": 0.2, "y": -0.4, "z": 0.1}},
    "phrases": [{"id": 0, "type": "blink", "t": [2.6, 2.8333],
                 "params": {"peak": "strong", "peak_dev": 0.44, "symmetry": "both",
                            "asymmetry": 0.05, "onset": 0.1, "offset": 0.0667},
                 "detail": {"eyeBlinkLeft": [<L1 分段>], "eyeBlinkRight": [<L1 分段>]}}],
    "residual": {"<57 个 L1 通道>": [<L1 分段>]}
  }]
}
```

- `track_start`：轨道第一帧在 clip 网格上的帧号；`time_sec`：该帧在容器时间轴上的时间（取自
  `features.npz` 的 `window_time_sec`），用于回到原视频抽帧。
- `detail` 与 `residual` 用 **L1 分段语法**（`t` 相对轨道起点）。`detail` 是短语时间段内、它所占通道的
  精确 L1 分段；编辑短语时丢弃（D4）。

## 3. L1 → L2（编码）

1. **拼接**：同一（clip, segment）的窗口是同一条序列的切片，重叠帧逐位相同（编码时断言）。拼回轨道，
   在整条轨道上运行 L1 编码 → **轨道级 L1**（一个旋转参考，masks 在轨道上一致）。
2. **静息值**：每个 L1 通道取轨道上被描述帧的 L1 值（refined、不平滑）的中位数；旋转取旋转向量各分量的中位数。
3. **检测**：每个短语类型一个确定性检测器，规则只写在 `schemas/l2_vocabulary.json`（import 时校验，
   与 `l1_rules.json` 同一模式）。检测在 L1 值相对 `rest` 的偏离上进行，事件边界落在 L1 分段边界上。
4. **归属**：短语占住（通道 × 时间段）格子，一个格子只归一个短语，冲突按词表优先级。
5. **残差**：L1 分段在短语时间段边界处切开：段内部分进短语 `detail`，其余进 `residual`。

## 4. L2 → L1（解码）

- **exact**：`residual` + 各短语 `detail` → 合并相邻的同档同值分段 → 与轨道级 L1 **逐字相同**（硬检查）。
- **phrase-only**：丢掉 `detail`，短语时间段由 §6 生成（第 1 步先用固定模板：静息值 → 峰值 → 静息值的
  梯形），量化、分段后与 `residual` 合并。
- 轨道级 L1 → 现有 `decode_window`（支持任意长度）→ 按原窗口位置切回窗口 → 现有 L1 解码链与 detail-net。

## 5. 知识库四层

| 层 | 内容 | 来源 | 位置 |
|---|---|---|---|
| ① 词表/本体 | 短语类型、通道、参数定义、FACS AU 对应、子类型、硬约束、检测规则 | 人工，LLM 起草 | `schemas/l2_vocabulary.json`（git） |
| ② 文献先验 | 典型时长、幅度、对称性、伴随动作，每条带出处与置信度 | 文献检索 + LLM 摘录，人工审核 | `docs/kb/priors.json`（git） |
| ③ 语料统计 | 每类参数分布、伴随通道条件概率、说话人间差异 | L1→L2 编码器 | `runs/<run>/l2/kb/`（按 run + 词表版本） |
| ④ 实例库 | 每个真实动作：来源（clip + 时间）、参数、关键点、相对 `rest` 的各通道轨迹 | 同上 | 同上 |

运行时解码不调用 LLM。LLM 的位置：建库时起草 ①②；使用时把自然语言编辑翻译成受 schema 约束的 L2
修改（查 ①② 以知道合法短语与参数范围）。不让 LLM 直接生成 L1 数值（不可复现、无数据依据、不可评测）。

## 6. 实例检索算法（phrase-only 解码的生成部分）

思路借鉴拼接式语音合成的 unit selection（Hunt & Black 1996）与游戏动画的 motion matching：
逐短语算**目标代价**，整条轨道用 Viterbi 最小化 **目标代价 + 衔接代价**。

### 6.1 查询与实例
- 查询 q：`type`、时长 d_q、显式参数 P_q（只含写了的）、上下文 C_q（目标轨道 `rest`、同时发生的短语类型、
  前后同类短语间隔、是否在说话）。
- 实例 e：同样字段的实测连续值 + 关键点（起、峰、止）+ 各通道偏离轨迹 + 来源说话人、来源 `rest`、质量。

### 6.2 第 0 步：硬过滤
类型相同；写了的类别参数一致；**只用训练集说话人**；质量达标；伸缩比 d_q/d_e ∈ [1/α, α]（α 初值 1.5）、
幅度缩放比有上限。无候选时按固定顺序放宽（伸缩上限 → 对称性 → 退回模板），放宽等级写入溯源并统计。

### 6.3 第 1 步：目标代价 T(q,e) = Σ w_k c_k（各项先除以该类型的语料标准差）
| 项 | 算法 |
|---|---|
| 时长 | \|log(d_q/d_e)\| / σ |
| 峰值 | 实例峰值偏离落在查询档位内为 0，否则到区间的距离 / σ |
| 起落形状 | 起、落占比之差 / σ（仅查询写了时） |
| 对称性 | 左右差之差 / σ |
| 静息兼容 | 相关通道 `rest` 距离 + 余量惩罚（rest_q + 缩放后偏离 > 1 的超出量） |
| 上下文 | 同时短语类型集合的 Jaccard 不匹配 + 说话状态不一致 + 同类间隔差 |
| 缺省先验 | 查询未写的参数：实例偏离语料中位数的 \|z\| × 小权重（没写就给典型的） |

权重 w_k 在验证集说话人上拟合（坐标下降/网格），目标是解码回 L1 的误差；保留前 K 个候选（K 初值 20）。

### 6.4 第 2 步：衔接代价与序列选择
min Σ T(q_i,e_i) + Σ J(e_i,e_{i+1})，J = 交界处共用通道的偏离值之差 + 不同来源说话人的 λ_spk
+ 短时间内重复用同一实例的惩罚。Viterbi，O(n·K²)。平局按实例 id → 确定性。可选采样模式：
softmax(−代价/τ) + 种子。

### 6.5 第 3 步：变换与合成
按关键点分段线性伸缩时间；同一短语所有通道共用一个幅度比例（保住伴随关系）；旋转在轨道参照的旋转向量
空间缩放；方向/对称性不符时可用已验证的左右镜像实例（detail-net 的 `augment.py`）；并发短语在偏离空间相加
→ + `rest` → 截断 [0,1] → 量化为 L1 → 并入残差。溯源：每短语记录实例、各项代价、放宽等级、伸缩与幅度比例。

α、K、λ_spk、τ、放宽顺序写入 `schemas/l2_retrieval.json`；拟合出的权重是运行产物（带词表版本）。

## 7. 评测

- **exact 往返**：所有轨道逐字一致（硬闸门）。
- **覆盖率**：偏离 `rest` 的相关事件中被短语解释的比例；被拒候选按原因计数（过长、过短、未全描述）。
- **压缩**：残差分段 + 短语数 vs 轨道级 L1 分段数。
- **phrase-only 损失**：短语时间段内、所占通道上，与 exact 的档位一致率与值误差，按短语类型列出。
- **检索对照**（第 3 步起）：固定模板 / 同类随机实例 / 只按时长最近 / 完整算法 / 神谕实例（按真实误差选的最优）。
  完整算法与神谕的差 = 代价函数的质量；神谕与真实的差 = 实例库的覆盖。另做代价项消融。
- **一致性**：同类实例的轨迹离散度（L2.3）。
- **编辑局部性**：改一个短语参数只影响它占的通道与时间段。
- **人工核对**：按检测时间点从原视频抽帧（`time_sec` + 帧号 / hz）。
