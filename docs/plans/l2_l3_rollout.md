# L2 / L3 逐步推进方案

*接续 `multilayer_semantic_representation.md`；L1 已落地（见 `decisions/l1_text_codec.md`）*

> **状态：PLANNED。** 2026-09-23 随 L1 实现一起定。本文只记意图与闸门；落地时的取舍另立
> `decisions/`。

---

## 0. 总原则

1. **每层文本 = 本层单元 + 下层残差。** L2 文本 = 动作短语 + 未被任何短语解释的 L1 原子段；
   L3 同理。这样每层往返都能完整回到 L1，误差可以精确归因到"本层压缩"而不是"丢了东西"。
2. **每一步都有可测的闸门**，不过闸门不进下一步。度量一律复用 `scripts/l1_report.py` 的
   A/B/C 口径（值误差、旋转测地角、`derive.py` 动力学误差、编辑局部性）。
3. **仓库边界**：本仓库产出数据、不放训练代码（CLAUDE.md）。规则/统计型的 L2 属于数据处理，
   放这里；L3 的生成模型训练属于建模仓库，本仓库只产出它需要的数据集
   `(tensor, L1, L2, 弱 L3 标注)`。

## 2. L2 动作短语层

### L2.1 规则种子词表（确定性）
- 在 L1 文本上写**手工模板检测器**，先做少数几何上无歧义的动作：
  `blink`（eyeBlinkL/R 同步升到 ≥moderate 且 ≤0.4 s 内恢复）、`jaw_open`、
  `smile`（mouthSmileL/R ≥slight 持续）、`brow_raise`（browInnerUp/OuterUp）、
  `nod`（head_rotation x 符号往返）。
- 词表放 `schemas/l2_vocabulary.json`（与 l1_rules 同一模式：JSON 是唯一真源、import 时校验）。
- 每个短语带参数：`onset`、`duration`、`peak_level`、`symmetry`（左右差）。
- **解码**：短语 → 模板化的 L1 段序列 → L1 解码。
- 交付：`src/semantic/l2.py`、`scripts/l2_report.py`。

### L2.2 数据驱动的候选发现（无监督但可复现）
- 在多 clip 的 L1 段上统计通道共激活（段级共现矩阵；窗口级 level 直方图做 NMF / 固定种子
  k-means），产出**候选**组合，人工命名后并入词表（词表带版本号）。
- 不直接把聚类 id 当短语：命名、审核这一步是"人可读"的保障。

### L2.3 词表内部一致性检查（原计划 §2 的风险项，必须过）
- 对每个短语标签：同标签实例的 L1 通道模式离散度 vs 异标签间距（silhouette / 标签内方差比）。
- 同时报告**覆盖率**（非 none 的 L1 段中被短语解释的比例）和**残差量**。
- 闸门：每个短语的一致性过阈值；不过的短语拆分或降回残差，不带病进 L3。

### L2 验收
- L2→L1→tensor 的误差减去 L1 误差 = 词表/模板引入的损失，分短语列出；
- 编辑一个短语参数（如 blink 时长）只改变该短语涉及的通道与时间段（沿用 L1 的局部性测试）。

## 3. L3 交流意图层

### L3.0 轴间独立性探索（原计划 §3 的"先验证再定轴"）
- **需要标注**，按获取成本排序：
  1. 自动弱标注：音频 VAD → 说话/倾听（scenario）；ASR 文本情感 → 粗情绪；
  2. 带情绪标签的公开数据（上线前需核对许可与标签定义，可用 arxiv 检索相关工作）；
  3. 小规模人工标注，只用于校验弱标注。
- 分析：给定各轴取值，L2 短语与 L1 通道的条件分布；"含义相同、场景不同"切片上的变化是否只
  落在部分通道；轴对之间的条件互信息。
- 交付：一份探索报告 + 一条 decision：amplitude 是独立轨道还是附着在 meaning 单元上的调制
  参数；每条轴的原生时间分辨率。

### L3.1 轴定义与时间结构（decision）
- 按 L3.0 结论定轴。倾向：amplitude 作为 meaning 单元的属性、情绪用秒级慢轨道、scenario 在话轮
  边界跳变。每条轨道用原生分辨率，解码到 L2 时再对齐。

### L3.2 L3→L2 映射
- 先做**查表/规则基线**（意图 → 短语模板分布），作为可解释的下界；
- 再在建模仓库训练条件生成模型（L3 → L2 短语序列），训练对由 L1/L2 自动生成
  （计划 §2.4 的弱监督来源）。本仓库负责导出数据集与评测脚本。

### L3.3 解耦评测
- 核心指标：编辑单条 L3 轴时，L1 通道变化中落在"预期子集"之外的比例（泄漏率），以及其余轴与
  无关几何的扰动；
- 误差三段归因：L3→L2（意图到动作是否合理）、L2→L1（动作到几何）、L1→tensor（量化下限）。
