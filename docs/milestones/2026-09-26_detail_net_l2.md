## 3. L2 与知识库

- **exact 往返 208 / 208 条轨道逐字一致**；压缩 223287 个 L1 分段 → 185828 残差 + 6353 短语（0.861）。

## 4. 没解决的问题

1. **检索的代价特征不够**：神谕比 KB 平均形状高 8–14 个百分点，拟合出的权重几乎只用 channel_dev。下一步：短语段两侧的残差值、
   §6.4 衔接代价。
2. **head_move 还原最弱**（约 58%）。
3. **smile 与说话嘴型混淆**（D3），单靠 L1 分不开。
4. **L1 小 bug**：`value_hint` 恰在档位边界（如 0.05）时同时落在相邻两档（`bin_bounds` 两端闭区间），把该段改到相邻档位后
   refined 解码不变。约 0.6% 的编辑受影响，尚未修。
5. **L1 平移分档**：头部平移 91% 的帧不是 none，阈值按单 clip 定，需重定。
6. 轨道级 L1 的 blendshape 误差（0.0148）略高于窗口级（0.0136），口径不完全相同，未深究。
7. scratch 上的数据可能被自动清理；`clips/` 里有大量下载失败留下的空目录。
